# Vimium Homemade

セキュリティ要件によりOSS拡張機能が使用できない環境向けに自作したVimium互換のChrome Extension。

**v1.2.6**

---

## インストール方法

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリのルートディレクトリを選択する

## 主要機能の詳細

### Link Hints
`f` / `F` でページ上の可視リンク・ボタンにラベルを表示。ラベル文字を入力すると対象を開く。スクロールしないと見えない要素（カルーセル外など）は対象外。

### Find Mode
`/` で起動。スマートケース対応（小文字のみ → 大文字小文字を無視、大文字を含む → 区別）。`n`/`N` で移動。

### `yc` — ブロックテキストコピー
`/` で検索後に `yc` を押すと、マッチを含む最近傍のブロック要素（`<p>`, `<li>`, `<td>` 等）のテキスト全体をコピー。`<div>` のような汎用コンテナの場合はビジュアルモードに移行して手動で範囲を選択できる。

### Vomnibar
`o`/`O` で起動。URL・ブックマーク・履歴を統合検索。`T` でタブ切り替えモード。

### スクロール
Vimiumのスムーズスクロール実装を移植。長押しでの速度キャリブレーション機能付き。テキスト入力中（`input`/`textarea`/`contenteditable`）はキーバインドを自動無効化。

### グリッドクリック
`m` キーで画面全体を格子状に分割するオーバーレイを表示し、**行（数字）→ 列（アルファベット）** の2ストロークで任意座標へマウスクリックを発火させる機能。Link Hints では検出できない要素（Canvas・カスタムUI等）の操作に使用する。

#### 操作手順

```
m         → グリッド表示
12        → 行12をハイライト（数字を続けて入力可）
A         → 列Aで一意確定 → 即クリック発火

m → 3 → AA  → 行3・列AA（2文字列）で確定 → クリック発火
```

| 入力 | 動作 |
|------|------|
| 数字 (`0`-`9`) | 行番号を入力（リアルタイムでハイライト更新） |
| アルファベット | 行を確定し列フェーズへ移行（前方一致で絞り込み） |
| `Enter` / `Space` | 行フェーズ: 行を確定して列入力待ちへ / 列フェーズ: 現在の候補の先頭でクリック発火 |
| `Backspace` | 1文字取り消し（列が空なら行フェーズに戻る） |
| `Escape` | グリッドを閉じてノーマルモードへ |

#### 列ラベルの仕様

Excel 式アルファベット表記。26列を超えると `AA`, `AB`, ... と2文字になる。

| 列番号 | ラベル |
|--------|--------|
| 1〜26 | A〜Z |
| 27〜52 | AA〜AZ |
| 53〜78 | BA〜BZ |
| … | … |

列入力は**前方一致の自動発火**方式。候補が1つに絞れた瞬間にクリックが走る（例: 26列以下なら1文字で即発火、26列超の場合は `A` を入力すると `AA`〜`AZ` 等との曖昧さが解消されるまで待機）。

#### 外観のカスタマイズ

オプションページ（`?` → 拡張機能オプション）の「グリッドクリック」セクションで以下を変更できる。

| 設定 | 内容 |
|------|------|
| 背景オーバーレイ濃さ | 暗転強度 0〜50 % |
| グリッド線 | 色 + 不透明度 0〜100 % |
| 辺ラベル | 行・列端ラベルの色 |
| 行ハイライト背景 | 行選択後の帯の色 + 不透明度 |
| セルラベル | ハイライト行内の列ラベルの色 |
| 辺ラベルフォントサイズ | 8〜24 px |
| セルラベルフォントサイズ | 8〜28 px |
| セルサイズ | 5〜120 px（小さいほど精度↑・ラベルが密になる） |

## 設定

`chrome://extensions/` → Vimium Homemade の「詳細」→「拡張機能のオプション」から設定ページを開ける。

| 設定項目 | 内容 |
|----------|------|
| スクロール量 | 1回のスクロールのpx数 |
| スムーズスクロール | ON/OFF |
| 半ページ比率 | `d`/`u` のスクロール量（画面高さの割合） |
| キーリピート | 長押し時のディレイ・インターバル |
| ヒント文字 | Link Hints に使用する文字セット |
| Vomnibar | 最大表示件数・履歴/ブックマークの有効無効 |
| HUDタイムアウト | メッセージの表示時間 |
| キーマッピング | カスタムキーバインド（`map`/`unmap`/`unmapAll` 形式） |
| 除外サイト | キーバインドを無効化するドメイン（ワイルドカード対応） |
| グリッドクリック | 色・透明度・フォントサイズ・セルサイズ（詳細は上記参照） |

## 制限事項

- `chrome://` URL では動作不可（ブラウザセキュリティポリシー）
- Chrome Web Store ページでは動作不可
- PDFビューアーでは動作不可
- `file://` は拡張機能の設定で手動許可が必要
